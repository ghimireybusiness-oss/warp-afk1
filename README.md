# Minecraft AFK Bot (Mineflayer • 1.21+)

A production-ready, modular AFK bot for Minecraft Java 1.21+ with:

- 🔁 Intelligent reconnect (Sonar AntiBot aware)
- 🧠 Human-like anti-AFK movement
- 🍗 Auto-eat / 🛏️ Auto-sleep / 💀 Auto-respawn
- 🛡️ Crash-proof (uncaughtException + unhandledRejection guards)
- 🚀 Optimized for 24/7 hosting on Railway, Render, Koyeb, VPS

---

## 1. Requirements

- **Node.js 20 LTS** (NOT Node 24 — incompatibilities with native deps)
- npm 9+
